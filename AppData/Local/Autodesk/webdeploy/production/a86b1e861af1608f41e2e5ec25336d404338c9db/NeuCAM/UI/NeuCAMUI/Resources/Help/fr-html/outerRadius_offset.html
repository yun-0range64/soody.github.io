Utilisez ce décalage pour modifier la position par rapport au point de référence sélectionné ci-dessus. Vous pouvez procéder aux ajustements positifs ou négatifs nécessaires.

Dans cet exemple:
Extérieur = Diamètre extérieur du brut (modèle + 1 mm de brut).
Retrait = Extérieur + décalage de 5 mm.
Dégagement = Retrait + décalage de 5 mm.

Dans cet exemple:
Intérieur = Diamètre intérieur du brut.
Retrait = Décalage intérieur de -0,120 po.
Dégagement = Décalage de retrait de -0,260 po.
