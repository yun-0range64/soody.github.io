SOODY 모바일 수어 학습 화면

1. 이 폴더에서 python -m http.server 8000 실행
2. PC: http://localhost:8000 접속
3. 모바일: HTTPS 배포 환경(예: GitHub Pages)에서 접속하고 카메라 권한 허용

화면 상단은 사용자가 제공한 원본 디자인을 이미지로 정확하게 표시합니다.
화면 하단은 실제 카메라 영상 + MediaPipe Hands 랜드마크를 표시합니다.
기존 sketch.js의 주먹 형태 판정 일부를 화면 비율에 맞게 이식한 프로토타입입니다.
'만나서 반갑습니다' 문장 전체의 수어 의미를 인식하는 AI 모델은 아닙니다.
튜터 이미지와 상단 문구는 현재 정적 이미지이며 나중에 애니메이션/인터랙션으로 분리할 수 있습니다.
인터넷 연결 필요: MediaPipe JS 및 모델 CDN.
